## Summary
### Key features
- Eight-channel 12-bit (AD5711R) and 16-bit (AD5710R) DACs, each channel independently configurable as an IDAC or VDAC [p1].
- Supplies: 2.7V to 5.5V (AVDD), 2.7V to AVDD (VDAC PVDDx), 1.71V to AVDD (IDAC PVDDx), and 1.08V to 1.98V (IOVDD) [p4].
- Output ranges: 0mA to 50mA in IDAC mode; 0V to VREF or 0V to 2 × VREF (50mA drive) in VDAC mode [p1].
- Guaranteed monotonicity with ±1 LSB_16 Max DNL, 70mV max VDAC headroom, and 0.25V max IDAC headroom [p1].
- On-chip 2.5V internal voltage reference with 3ppm/°C typical drift [p1].
- Addressable SPI interface (CS, SCLK, SDI, SDO) supporting up to 50MHz write and 25MHz read rates [p12].
- Packaged in a 2.1mm × 2.2mm, 25-ball WLCSP for -40 °C to +125 °C operation [p1].
### General operation
- Each channel comprises an input register, DAC register, DAC core, and output amplifier; PVDD0 powers OUT[3:0] and PVDD1 powers OUT[7:4] [p24].
- Channels default to powered-down high-Z IDAC mode and are configurable as IDACs or buffered VDACs (sourcing 50mA, sinking 10mA) [p24].
- Outputs update immediately via DAC register writes, or simultaneously from input registers via the /LDAC pin or software LDAC registers [p28].
- VREF defaults to an external input or outputs the internal 2.5V reference; a 27:1 multiplexer routes channel voltage, current, supplies, or die temperature to MUX_OUT [p25].
- Typical applications: optical networking, instrumentation, data acquisition, automatic test equipment, and process control and industrial automation [p1].
