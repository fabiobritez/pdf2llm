## Summary
### Key features
- High-efficiency buck-boost converter delivering 2-A output current (V_I ≥ 2.3 V, V_O = 3.3 V) [p1].
- Voltage ranges: input 1.3 V min to 5.5 V max (V_I > 1.8 V required during startup until power good); output 1.8 V min to 5.2 V max [p5].
- Supply current into VIN: 11 μA typ quiescent at T_J = 25°C, EN = V_IN = 3.6 V, V_OUT = 3.3 V, not switching; shutdown current 45 nA typ and 600 nA max with EN low, V_IN = 3.6 V, V_OUT = 0 V, specified over -40°C ≤ T_J ≤ 85°C (typical at 25°C) [p6].
- Feedback voltage: 500 mV typ (-1 % min to 1 % max PWM accuracy); peak current limit: 5 A typ (buck-boost), 3.8 A typ (buck) [p6].
- Typical switching frequency at V_OUT = 3.3 V, no load, MODE = HIGH, T_J = 25°C: 2.1 MHz in boost at V_IN = 2.3 V, 1.4 MHz in buck-boost at V_IN = 3.3 V, and 1.6 MHz in buck at V_IN = 4.3 V. Typical line regulation: 0.3 % for V_IN = 2.4 to 5.5 V, V_OUT = 3.3 V, I_OUT = 2 A. Typical load regulation: 0.1 % for V_IN = 3.6 V, V_OUT = 3.3 V, I_OUT = 0 to 2 A, forced PWM; typical values at T_J = 25°C [p7].
- Package: 10-Pin VSON-HR (0.5 mm pitch, 3.0 mm × 2.0 mm nom body size); 21.5 mm^2 solution size [p1].
- Operating junction temperature range: -40 °C min to 125 °C max [p5].
### General operation
- Four internal switches provide synchronous conversion, automatically transitioning between buck, 3-cycle buck-boost, and boost modes [p9] (the p1 description calls it a 4-cycle buck-boost mode, as printed).
- Peak current mode control uses an outer FB voltage loop (error amplifier and type-2 compensation) to drive an inner MOSFET current loop [p10].
- Control pins: EN enables/disables the device, MODE selects power save (LOW) or forced PWM (HIGH), FB senses feedback, and PG indicates open-drain power good [p4].
- External resistive divider sets adjustable output voltage for pre-regulators, point-of-load, battery back-up, and TEC supplies, with soft start, load disconnect, and overtemperature/overvoltage protection [p1].
