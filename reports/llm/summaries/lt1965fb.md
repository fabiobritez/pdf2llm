## Summary
### Key features
- Low-noise, low-dropout linear regulators supplying 1.1A output current in fixed-voltage versions or an adjustable version (1.20V reference). [p1]
- Input range is 1.8V to 20V; output is adjustable from 1.20V to 19.5V or fixed at 1.5V, 1.8V, 2.5V, or 3.3V. [p1]
- Dropout voltage at 1.1A load is 0.31V typ, 0.36V max at 25°C (0.49V max over temperature, T_J < 125°C). [p4]
- For the adjustable version at 0mA load and V_IN = V_OUT(NOMINAL) + 1V, GND pin current is 0.5mA typ, 1.1mA max; fixed versions typically add 100µA. Output noise is 40μV_RMS typ at 25°C with C_OUT = 10μF, I_LOAD = 1.1A, and bandwidth 10Hz to 100kHz. [p4 to 5]
- At 25°C, shutdown quiescent current is 0.01µA typ, 1µA max with V_IN = 6V and V_SHDN = 0V; ripple rejection is 57dB min, 75dB typ at 120Hz with V_IN − V_OUT = 1.5V average, 0.5V_P-P input ripple, and I_LOAD = 0.75A. [p5]
- Packages include 5-lead TO-220, 5-lead DD-Pak, thermally enhanced 8-lead MSOP, and 8-lead 3mm × 3mm DFN. [p1]
- Operating junction temperature range is -40°C to 125°C (E-, I-grades) and -40°C to 150°C (H-grade). [p2]
### General operation
- Fixed versions use the SENSE pin (100µA bias current) for error amplifier feedback; the adjustable version uses ADJ (1.20V reference, 1.3µA typical bias current). [p11]
- Two external resistors set adjustable V_OUT (R1 < 12.1kΩ recommended); a minimum 10μF output capacitor with ESR of 0.3Ω or less is recommended to prevent oscillations. [p12]
- Pulling /SHDN low turns off the output for shutdown; drive with logic or an open collector/drain with a pull-up resistor, or tie to V_IN if unused. [p11]
- Internal reverse-battery, reverse-current, foldback current-limit, and thermal protection suit logic supplies, switching post-regulators, instrumentation, and RF/DSP supplies. [p1]
