## Summary
### Key features
- Temperature sensor monitoring one local channel and three remote diode-connected transistor channels [p1].
- Operating supply voltage (V_DD) is 3.0V min, 3.3V typ, and 3.6V max [p2].
- Supply current (I_DD) is 2.5μA typ, 7μA max in standby, and 700μA typ, 1200μA max operating (β compensation disabled) [p2].
- Features 12-bit, 0.0625°C resolution and a -64°C to +150°C remote temperature-measurement range [p1].
- Remote temperature accuracy is -1°C min to +1°C max (T_A = 0°C to +70°C; T_RJ = 0°C to +100°C) [p2].
- Local accuracy is -1°C min to +1°C max (T_A = 0°C to +70°C); channel conversion time is 100ms max (β compensation disabled) [p3].
- SMBus/I^2C interface (eight slave addresses); -40°C to +125°C operation in 10-pin µMAX and 12-pin, 3mm x 3mm TDFN packages [p1].
### General operation
- Internal current source, multiplexer, and ADC sequentially measure remote channels 1, 2, 3, and the local channel into temperature registers [p8].
- Series-resistance cancellation and beta compensation correct remote sensor errors, while a highest temperature register reports the hottest channel [p1].
- Configuration register (13h) selects continuous-conversion or software-standby (stop) mode, one-shot conversions, extended-range format, and fault queue depth [p14].
- Controlled via I^2C/SMBus pins (SDA, SCL) and address input (ADD), with an active-low open-drain THERM output for comparator or interrupt alerts [p7].
- Typically monitors local PCB temperature and remote temperatures of CPUs, ICs with sensing diodes, or discrete diode-connected transistors [p45].
